# RSR SHOP V22.4

Professional marketplace-style Robux order workflow.

## Highlights

- CT/NCT gamepass product verification and exact-price inventory
- Verified gifting recipient, multiple gift items, quantities, optional item links, and verified game
- Required-field checkout gate
- Unique transaction ID on every order
- Live chat composer that is not replaced during polling
- Mobile/desktop responsive PWA

## Render

- Build: `node --check server.js`
- Start: `npm start`
- Root directory: blank when files are in repository root
